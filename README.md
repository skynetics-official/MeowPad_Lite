# MeowPad Lite v0.2

Статический сайт для старого iPad / Safari. Не требует собственного сервера.

## Что есть
- YouTube Lite через переключаемые публичные Invidious-инстансы.
- Разбор обычной YouTube-ссылки или поискового запроса.
- Режим фильма по ссылке.
- Встроенный iframe-плеер, если сайт разрешает встраивание.
- Прямой HTML5-плеер MP4/HLS/M3U8.
- Кнопка открытия прямого потока в нативном Safari-плеере.
- Специальная кнопка для присланного примера `neprikasaemye-lordfilm.top` → отдельный iframe-плеер.
- История последних ссылок хранится только в localStorage на устройстве.

## GitHub Pages
1. Создай новый публичный репозиторий.
2. Загрузи `index.html` в корень репозитория.
3. Открой Settings → Pages.
4. Source: Deploy from a branch.
5. Branch: main / root.
6. Открой выданную GitHub Pages ссылку на iPad.
7. Safari → Поделиться → На экран «Домой».

## Ограничения
GitHub Pages не может читать HTML произвольного чужого сайта через сервер, вытаскивать скрытые видеопотоки или перекодировать видео. Поэтому универсальное извлечение плеера из любой страницы без сервера невозможно. Прямые MP4/HLS/M3U8 и разрешённые iframe-плееры работают лучше всего.
