# MeowPad Lite v0.3

Лёгкая страница для старого iPad / Safari iOS 12.

## Что нового
- отдельная вкладка «Аниме»;
- режим YummyAnime с обрезкой страницы до области плеера;
- кнопки «Выше / Ниже» для ручной подгонки области плеера;
- положение сохраняется в localStorage;
- серии выбираются внутри встроенного плеера;
- готовая кнопка для «Мифические звери 6»;
- сохранены YouTube Lite, фильмы, прямой MP4/M3U8 и плеер 1+1.

## Важно
GitHub Pages не имеет серверной части. Поэтому сайт не может автоматически извлекать скрытую ссылку Kodik из любой страницы YummyAnime. Режим аниме показывает исходную страницу внутри iframe и визуально обрезает лишнюю часть. Если YummyAnime запретит встраивание через iframe или изменит верстку, используйте обычное открытие страницы или подстройте положение кнопками.

## Установка на GitHub Pages
Загрузите `index.html` в репозиторий и включите GitHub Pages для ветки, где лежит файл.
